## Поток данных одного шага

1. `Agent` берёт `PageModel` (компактный снапшот) и рендерит его в блок текста
   (`render_page_model`, режим `full` на первом шаге, дальше `delta`).
2. `ContextManager` собирает сообщения: системный промпт, задача, сводка старых шагов,
   скрэтчпад `notes`, окно последних шагов, текущий блок страницы — с соблюдением бюджета.
3. Провайдер возвращает текст + `tool_calls` (может быть несколько за ход).
4. Каждый вызов проходит через `SecurityPolicy.classify` → при `destructive` требуется
   `ui.confirm`; отказ возвращается модели как неудача, а не молча пропускается.
5. `ActionExecutor` выполняет действие: разрешает `[data-webpilot-id=N]` в нужном фрейме,
   скроллит к элементу, проверяет перекрытие, кликает/печатает, ждёт «успокоения» страницы и
   **сравнивает состояние до/после** (URL, хеш страницы, значение поля).
6. Результат превращается в `ToolResult` + свежий `PageModel`; шаг пишется в `StepRecord`,
   событие — в UI и в JSONL-транскрипт.
7. При повторяющихся отказах подключается recovery-субагент; при повторе одного и того же
   состояния страницы — предупреждение о цикле; по достижении лимитов — честный частичный
   ответ.

## Границы ответственности

| Модуль | Отвечает за | Не знает про |
|---|---|---|
| `browser/*` | браузер, снапшоты, исполнение действий, верификация | LLM, политику безопасности |
| `llm/*` | транспорт провайдеров, ретраи, usage | страницы, инструменты (видит только схемы) |
| `agent/*` | цикл, инструменты, контекст, субагенты | конкретные сайты и шаги задач |
| `security/*` | риски и подтверждения | как исполняется действие |
| `cli.py` | отображение и ввод человека | внутренности цикла |

Такое разделение позволяет тестировать всё офлайн: браузер — на локальном тест-сайте,
провайдеры — на canned-JSON, цикл — со стаб-исполнителем и scripted-моделью.

## Ключевые инварианты (закреплены тестами)

* **Никаких селекторов в коде.** Единственная форма адресации — `[data-webpilot-id=N]`,
  генерируемая из id, который выдал снайфер. Плюс grep-тест против «зашитых» путей/селекторов.
* **Сырой HTML не попадает в контекст основного цикла.** Только в субагента-экстрактора.
* **Каждое действие верифицируется.** «Кликнул» ≠ «сработало»: сравнивается состояние.
* **Бюджет токенов — жёсткий.** Контекст-менеджер не превышает `context_token_budget`
  (стресс-тест на 200 шагов).
* **Деструктивное — только с человеком.** Кроме `--confirm-mode allow` и домена из
  allow-списка, и всегда с записью в аудит.
